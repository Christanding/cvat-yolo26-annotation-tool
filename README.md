# YOLO26 图片标注软件

本仓库用于开发图片标注软件，为后续 YOLO26 模型训练提供可靠、可追溯的标注数据。

## 当前阶段

- 已完成 Git 仓库初始化。
- 已确定以 CVAT Community 为底座，采用 Windows 本地 Docker Compose 单用户部署。
- MVP 产品需求已冻结，详见 [REQUIREMENTS.md](REQUIREMENTS.md)。
- 尚未引入 CVAT 源码或开始功能开发。

## 基本原则

- 人工确认后的标注才可作为训练真值。
- 原始图片不得被静默覆盖或改写。
- 源代码与数据集、模型权重、训练输出分开管理。
- 导出前校验图片与标签配对、类别顺序、坐标范围和空标注。

## 大文件

数据集、模型权重和训练产物默认不提交到 Git。确需版本化的大文件应单独评估 Git LFS 或对象存储方案。
